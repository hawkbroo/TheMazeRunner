## Главное меню — погоня (`MenuChase`)

**Файлы:** `src/MenuChase.hpp`, `src/MenuChase.cpp`, подключено в `Game.cpp`

| Параметр | Значение |
|----------|----------|
| Позиция Y | `winH * 0.38f` (между названием на фоне и списком уровней) |
| Список уровней | `y = winH * 0.54f` |
| Скорость | 240 px/s |
| Дистанция игрок–монстр | **500 px** (`MONSTER_OFFSET`) |
| Игрок | `player_sheet`, `COL_RIGHT`, run A/B, origin Y **0.55** |
| Монстр | evil `ROW_TRANSFORM`, col 4 (±1), origin Y **0.70**, scale **×1.06** |
| Низ моделек | `alignedMonsterY()` — нижний край монстра = нижний край игрока |

**Логика выхода за край (важно):**
- Игрок уходит за **правый** край → **скрывается**, не появляется слева сразу (`waitingForMonster_ = true`)
- Монстр **добегает** до правого края сам
- Только после выхода монстра оба телепортируются: игрок `-EDGE_PAD`, монстр `-EDGE_PAD - 500`
- Пользователь явно просил: игрок не должен появляться слеva, пока монстр не зайдёт за правый край

**История правок MenuChase (сессия 5):**
- Старт: видео из Downloads → откат
- Потом: спрайты `MenuChase` на `player_sheet` + evil monster
- Дистанция: 105 → 165 → 280 → 420 → **500**
- Высота: 47% → 43% → **38%**
- Якорь монстра 0.64→0.70 + выравнивание низа
- Отдельные `playerX_` / `monsterX_` + `waitingForMonster_`

## Рассуждения агента (важно)

- **SFML не играет MP4/GIF напрямую** — только spritesheet + таймер (портал, меню-видео пробовали так).
- **Патруль:** без `lockPatrolAxis` монстр сворачивает на перекрёсток — фиксили на ур.2–3.
- **Chase idle-патруль:** когда игрок далеко, chase-монстр ходит по `patrolDir` (`updatePatrol` в `updateChase`).
- **MenuChase wrap:** нельзя телепортировать обоих одновременно — иначе монстр «пропадает» с экрана раньше игрока.
- **Evil monster в меню:** `ROW_TRANSFORM`, последний col (рот открыт); не `ROW_RUN`.
- **Выравнивание низа:** разные origin Y (игрок 0.55, монстр 0.70) + `alignedMonsterY()`.
- **Death anim игрока:** проблема в нарезке `player_sheet` (ряды 4–7), не только в коде — пользователь откатил правки.
- **Run-sheet отдельно:** пользователь откатил — остаётся 8-направленный `player_sheet`; зеркало влево через `COL_LEFT` / отриц. scale в старом коде.
