# The Maze Runner

Игра-лабиринт на **C++17** и **SFML 2.6** для Visual Studio 2022 (x64).

## Запуск за 2 шага

### 1. Установить SFML (один раз)

Дважды щёлкните **`SETUP.bat`** в папке проекта.

Скрипт сам найдёт скачанный `*SFML*.zip` в **Загрузках** (или на Рабочем столе), распакует в `third_party\SFML` и настроит проект. DLL копируются автоматически при каждой сборке.

> Нужен **SFML 2.6.1**, Visual C++ 17 (2022), **64-bit**. Если скачали SFML 3 — возьмите 2.6.1: https://www.sfml-dev.org/download/sfml/2.6.1/

### 2. Собрать и играть

1. Откройте **`TheMazeRunner.sln`** в Visual Studio  
2. Вверху: **x64** + **Debug**  
3. **Ctrl+F5** (запуск без отладки)

После первой сборки можно запускать **`ИГРАТЬ.bat`** — он откроет уже собранную игру.

## Быстрый старт (куда нажимать)

### 1. Скачать SFML (если SETUP.bat не нашёл архив)

1. Откройте https://www.sfml-dev.org/download/sfml/2.6.1/  
2. Скачайте **Visual C++ 17 (2022) — 64-bit**  
3. Положите zip в **Загрузки** и снова запустите **SETUP.bat**

### 2. Открыть решение

1. Запустите **Visual Studio**  
2. **Файл → Открыть → Проект/решение**  
3. Выберите `TheMazeRunner.sln` из этой папки  
4. Вверху выберите конфигурацию **x64** и **Debug** или **Release**

### 3. Собрать

1. Меню **Сборка → Собрать решение** (или **Ctrl+Shift+B**)  
2. DLL скопируются в папку exe автоматически

### 4. Запуск

1. **Отладка → Запуск без отладки** (**Ctrl+F5**)  
2. В меню выберите уровень **стрелками вверх/вниз** или **цифрами 1–5**, затем **Enter**  
3. Управление в игре: **W A S D** или стрелки, **Esc** — выход

## Управление и правила

| Клавиша | Действие |
|---------|----------|
| ↑ / ↓ | Выбор уровня в главном меню |
| 1–9, NumPad 1–9 | Быстрый выбор уровня в меню |
| Enter | Начать выбранный уровень / следующий уровень / в меню |
| WASD / стрелки | Движение в игре |
| Esc | Выход |

- Нужно дойти до **зелёного выхода** до окончания таймера.  
- **Оранжевые** круги — патрульные монстры (уровни 1–3).  
- **Красные** при погоне — преследующие (уровни 4–5).  
- Касание монстра — поражение.

## Уровни

1. 90 с, 1 патрульный монстр, медленно  
2. 75 с, 2 патрульных  
3. 60 с, 3 патрульных, быстрее  
4. 50 с, 2 преследователя  
5. 40 с, 3 преследователя, сложнее
