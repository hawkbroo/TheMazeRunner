# The Maze Runner

Игра-лабиринт на **C++17** и **SFML 2.6** для Visual Studio 2022 (x64).

## Сборка и запуск

1. Запустите **`SETUP.bat`** — скрипт найдёт SFML в Загрузках и настроит проект.
2. Откройте **`TheMazeRunner.sln`**, выберите **x64** + **Debug**.
3. **Ctrl+F5** — запуск без отладки.

Нужен SFML **2.6.1**, MSVC 2022, **64-bit**: https://www.sfml-dev.org/download/sfml/2.6.1/

## Управление

| Клавиша | Действие |
|---------|----------|
| ↑ / ↓, 1–5 | Выбор уровня в меню |
| Enter | Начать уровень / далее |
| WASD / стрелки | Движение |
| Esc | Выход / в меню |

Дойти до **зелёного выхода** до конца таймера. Касание монстра — поражение.

## Уровни

1. 90 с, 1 патруль  
2. 75 с, 2 патруля  
3. 60 с, 3 патруля  
4. 50 с, 2 преследователя  
5. 40 с, 3 преследователя
